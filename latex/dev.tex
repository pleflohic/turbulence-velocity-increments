\begin{abstract}
We derive asymptotic approximations for velocity increment PDFs in the multifractal propagator framework. Using Laplace's method, we obtain two solutions: a simplified form assuming a fixed saddle point, and a better approximation via the Lambert W function. Numerical tests against the full propagator integral reveal where each approximation works best, providing groundwork for entropy calculations.
\end{abstract}

\section{Introduction}

Turbulent flows exhibit intermittency: velocity fluctuations become increasingly non-Gaussian at smaller scales. The fluctuations at scale $\ell$ can be studied with the velocity increments equation.

The multifractal approach describes intermittency through local Hölder exponents $h$ distributed according to a spectrum $D_E(h)$. Chevillard et al.~\cite{chevillard2012} proposed a propagator formalism where increment PDFs appear as integrals over the Hölder distribution, allowing for Gaussian large-scale statistics with small-scale intermittency.

We use the Kolmogorov--Oboukhov lognormal model with $D_E(h) = 1 - (h-c_1)^2/(2c_2)$. This gives tractable expressions while capturing intermittency. Since the propagator integrals lack closed forms, we apply Laplace's method for asymptotic approximations at small scales.

The paper proceeds as follows. Section 2 establishes the Hölder distribution and propagator integral. Section 3 derives two approximations of the increment PDFs: assuming a fixed saddle point (Case A), and then using the Lambert W function (Case B). We compare both approximations numerically against the full integral to assess their accuracy. Section 4 introduces standardized PDFs using the same pathway as in section 3.

\section{Starting point: the distribution of $h$}

The multifractal formalism for velocity increments can be interpreted as a continuous mixture of Gaussian variables. More precisely, the velocity increment at scale $\ell$, denoted as $\delta_{\ell}u$, is modeled as a Gaussian random variable conditioned on a fluctuating singularity exponent $h$ (Chevillard et al., 2012, Eq.~10) :

\begin{equation}
\delta_{\ell}u \stackrel{\text{law}}{=} \sigma \left( \frac{\ell}{L} \right)^h \delta
\tag{0}
\end{equation}

where $\sigma$ represents the characteristic velocity of the flow at the integral scale $L$, $\delta$ is a zero-mean, unit-variance Gaussian white noise, and $h$ is a fluctuating variable independent of $\delta$, whose probability density function $\mathcal{P}_h^{(\ell)}$ is governed by a singularity spectrum $\mathcal{D}(h)$.

$\\[0.01em]$
We now use (Chevillard et al., 2012, Eq.~11), which provides the probability density function of $h$ :
\begin{equation}
\mathcal{P}_h^{(\ell)}(h)
=
\frac{
\left(\tfrac{\ell}{L}\right)^{1-\mathcal{D}^E(h)}
}{
\displaystyle \int_{h_{\min}}^{h_{\max}}
\left(\tfrac{\ell}{L}\right)^{1-\mathcal{D}^E(h)}\,\mathrm{d}h
}.
\tag{1}
\end{equation}

using the Kolmogorov–Oboukhov log-normal spectrum
\[
\mathcal{D}^E(h)=1-\frac{(h-c_1)^2}{2c_2},
\]
with \(h_{\min}=-\infty\) and \(h_{\max}=+\infty\),
we obtain
\begin{equation}
\mathcal{P}_h^{(\ell)}(h)
=
\frac{
\exp\!\left[-\tfrac{(h - c_1)^2}{2c_2}\ln\!\left(\tfrac{L}{\ell}\right)\right]
}{
\displaystyle \int_{-\infty}^{+\infty}
\exp\!\left[-\tfrac{(h - c_1)^2}{2c_2}\ln\!\left(\tfrac{L}{\ell}\right)\right]
\mathrm{d}h
}.
\tag{2}
\end{equation}

To simplify notation, we define

\begin{equation}
\alpha = -\ln\!\left(\frac{\ell}{L}\right) > 0.
\tag{3}
\end{equation}

Then the expression becomes
\begin{equation}
\mathcal{P}_h^{(\ell)}(h)
=
\frac{
\exp\!\left[-\frac{\alpha}{2c_2}(h - c_1)^2\right]
}{
\displaystyle \int_{-\infty}^{+\infty}
\exp\!\left[-\frac{\alpha}{2c_2}(h - c_1)^2\right]
\mathrm{d}h
}.
\tag{4}
\end{equation}

The denominator is a Gaussian integral:
\begin{equation}
\int_{-\infty}^{+\infty}
e^{-\frac{\alpha}{2c_2}(h - c_1)^2}\mathrm{d}h
= \sqrt{\frac{2\pi c_2}{\alpha}}.
\tag{5}
\end{equation}

Hence,
\begin{equation}
\boxed{
\mathcal{P}_h^{(\ell)}(h)
=
\sqrt{\frac{\alpha}{2\pi c_2}}\,
\exp\!\left[-\frac{\alpha}{2c_2}(h - c_1)^2\right].
}
\tag{6}
\end{equation}

\section{Non-normalized PDF}

\subsection{General form of the PDF}

We now consider the probability density function of velocity increments. It's a function of the position x. According to (Chevillard et al., 2012, Eq.~17) :
\begin{equation}
\mathcal{P}_{\delta_\ell u}(x)
= \frac{1}{2\pi\sigma}\,
\sqrt{\frac{\alpha}{c_2}}
\int_{-\infty}^{+\infty}
\exp[-f(h,\alpha,x)]\,\mathrm{d}h.
\tag{7}
\end{equation}

with
\begin{equation}
f(h,\alpha,x)
= \alpha\!\left(\frac{(h-c_1)^2}{2c_2}-h\right)
+ \frac{1}{2}\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h}
\tag{8}
\end{equation}



$\\[0.8em]$
We would like to get an explicit form of our Eq.~7. To do so, we'll use Laplace's approximation (see Appendix).
Knowing that
\begin{equation}
\forall h \in \mathbf{R},
\quad
\frac{\partial f}{\partial h}(h,\alpha,x)
= \alpha\!\left(\frac{h-c_1}{c_2}-1\right)
+ \alpha\!\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h}
\tag{9}
\end{equation}

we have :
\begin{equation}
\forall h \in \mathbf{R},
\quad
\frac{\partial^2 f}{\partial h^2}(h,\alpha,x)
=
\frac{\alpha}{c_2}
+ 2\alpha^2
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h}
\quad > 0
\tag{10}
\end{equation}

We just need to verify that $h^\star$ is such that
$\frac{\partial f}{\partial h}(h^\star,\alpha,x) = 0$
to be able to use Laplace approximation.

$\\[0.3em]$
In this case, by applying the approximation to Eq.~7, we get :

\begin{equation}
\boxed{
\mathcal{P}_{\delta_\ell u}(x)
\approx
\sqrt{\frac{\alpha}{
2\pi c_2 \sigma^2 \frac{\partial^2 f}{\partial h^2}(h,\alpha,x))
}}\,
\exp[-f(h^\star,\alpha,x)].
}
\tag{11}
\end{equation}


$\\[0.1em]$
i.e
\begin{equation}
\boxed{
\begin{aligned}
\mathcal{P}_{\delta_\ell u}(x)
\approx
\frac{1}
{
\sqrt{2\pi}
\sqrt{
2\alpha c_2 x^2 e^{2\alpha h^{\star}}
+ \sigma^2}}
\times
\exp\!\left[
-\alpha\!\left(
\frac{(h^\star-c_1)^2}{2c_2}-h^\star
\right)
-\frac{1}{2}
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h^\star}
\right]
\end{aligned}
}
\tag{12}
\end{equation}

We provide plots of the obtained PDF using Julia programming language.

\subsection{Case A: assuming \(h^\star = c_1\)}

As a first approximation, we can consider that :

\begin{equation}
\frac{\partial f}{\partial h}(h^\star,\alpha,x)\Big|_{h^\star=c_1}
= 0
\tag{13}
\end{equation}

$\\[0.1em]$
We can use the Laplace approximation given by Eq.~12, which becomes :

\begin{equation}
\boxed{
\begin{aligned}
\mathcal{P}_{\delta_\ell u}(x)
\approx
\frac{1}{\sqrt{2\pi}}
\frac{1}
{
\sqrt{
2\alpha c_2 x^2 e^{2\alpha c_{1}}
+ \sigma^{2}}}
\times
\exp\!\left[
\alpha c_1
-\frac{1}{2}\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha c_1}
\right]
\end{aligned}
}
\tag{14}
\end{equation}

$\\[0.05em]$
Here are plots of the obtained PDF using Julia programming language.

\subsection{Case B: solving \(\frac{\partial f}{\partial h}(h,\alpha,x)=0\) via the Lambert \(W\) function}

From \((8)\),
\begin{equation}
\frac{\partial f}{\partial h}(h,\alpha,x)
= \alpha\!\left(\frac{h-c_1}{c_2}-1\right)
+ \alpha\!\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h}
\tag{15}
\end{equation}
Set to zero:
\begin{equation}
h - (c_1 + c_2)
= -c_2
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha h}
\tag{16}
\end{equation}
Multiply by \(-2\alpha\) and let \(u=-2\alpha(h-c_1-c_2)\):
\begin{equation}
u
= 2\alpha c_2
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha(c_1 + c_2)-u}
\tag{17}
\end{equation}
Consequently
\begin{equation}
u e^{u}
= 2\alpha c_2
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha(c_1 + c_2)}
\tag{18}
\end{equation}
Hence
\begin{equation}
\boxed{
h^\star(\alpha,x)
= (c_1 + c_2)
- \frac{1}{2\alpha}
W\!\left(
2\alpha c_2
\left(\frac{x}{\sigma}\right)^{2}
e^{2\alpha(c_1 + c_2)}
\right)
}
\tag{19}
\end{equation}
where \(W\) is the Lambert \(W\) function (the inverse of \(w\mapsto we^w\)).

$\\[0.1em]$
We can now plug the obtained $h^\star$ into Eq.~12. Here are plots of the obtained PDF using Julia programming language.


\begin{figure}[H]
    \centering
    \includegraphics[clip, width=1.0\textwidth]{images/non_normalized_figures/pdf3.png}
    \caption{$\mathcal{P}_{\delta_\ell u}$ plots in linear and log scales using Laplace approximation with $h^\star$ from Lambert W (Julia, QuadGK)}
    \label{fig:pdf3}
\end{figure}

$\\[0.1em]$
Comparing the plots, it is clear that the approximation using the Lambert W function is better than the one assuming $h^\star = c_1$.

\section{Normalized PDF}

According to (Chevillard et al., 2012, Eq.~12), the $p$-th order moment of the velocity increment
is expressed as
\begin{equation}
\langle |\delta_\ell u|^p \rangle \underset{\ell \to 0}{\approx} \sigma^2 \langle |\delta|^p \rangle \left(\frac{\ell}{L}\right)^{\zeta_p},
\quad\text{with}\quad
\zeta_p = \min_h \bigl[ p h + 1 - \mathcal{D}^E(h) \bigr] \quad\text{and}\quad \delta \sim \mathcal{N}(0,1).
\tag{21}
\end{equation}

Using the Kolmogorov–Oboukhov log-normal spectrum
\begin{equation}
\mathcal{D}^E(h) = 1 - \frac{(h - c_1)^2}{2c_2},
\tag{22}
\end{equation}

the minimization problem is
\begin{equation}
\frac{\mathrm{d}}{\mathrm{d}h}
\bigl[p h + 1 - \mathcal{D}^E(h)\bigr] = 0
\quad i.e. \quad
\frac{\mathrm{d}}{\mathrm{d}h}
\bigl[p h + \frac{(h-c_1)^2}{2c_2}\bigr] = 0
\tag{23}
\end{equation}

Hence, the minimizing exponent is
\begin{equation}
h_p = c_1 - p c_2,
\tag{24}
\end{equation}
and inserting this value into Eq.~20 gives
\begin{equation}
\zeta_p = p c_1 - \frac{p^2}{2} c_2
\tag{24}
\end{equation}

In particular, for the second-order :
\begin{equation}
\zeta_2 = 2(c_1 - c_2)
\tag{26}
\end{equation}

Knowing that $\langle |\delta|^2 \rangle = 1$, we get :
\begin{equation}
\boxed{
\langle (\delta_\ell u)^2 \rangle
\underset{\ell \to 0}{\approx}
\sigma^2 \left( \frac{\ell}{L} \right)^{2(c_1 - c_2)}.
}
\tag{27}
\end{equation}

We now define a normalized increment
\begin{equation}
\boxed{
\delta_\ell \nu
= \frac{\delta_\ell u}{\sqrt{\langle (\delta_\ell u)^2 \rangle}}
= \frac{\delta_\ell u}{\sigma \left( \frac{\ell}{L} \right)^{c_1 - c_2}}
}
\tag{28}
\end{equation}

$\\[0.3em]$
This normalization ensures that
\begin{equation}
\langle (\delta_\ell \nu)^2 \rangle = 1,
\tag{29}
\end{equation}
for all scales $\ell/L$, so that all normalized PDFs can be directly compared across scales.

$\\[0.1em]$
We thus have $\delta_\ell \nu\ = \delta_\ell u / \sigma \left( \frac{\ell}{L} \right)^{c_1 - c_2} = g(\delta_\ell u)$ where $g(x) = x / \sigma \left( \frac{\ell}{L} \right)^{c_1 - c_2}$ is monoton and differentiable.


$\\[0.1em]$
Knowing that : $\mathcal{P}_{\delta_\ell \nu}(x) = \left| \frac{1}{g'(g^{-1}(x))} \right| \mathcal{P}_{\delta_\ell u}(g^{-1}(x))$
, we have : $\mathcal{P}_{\delta_\ell \nu}(x) = \sigma \left( \frac{\ell}{L} \right)^{c_1 - c_2} \mathcal{P}_{\delta_\ell u}(\sigma \left( \frac{\ell}{L} \right)^{c_1 - c_2}x)$
i.e.

\begin{equation}
\boxed{
\mathcal{P}_{\delta_\ell \nu}(x) = \sigma e^{\alpha (c_2 - c_1)} \mathcal{P}_{\delta_\ell u}(\sigma e^{\alpha (c_2 - c_1)}x)
}
\tag{30}
\end{equation}

$\\[0.1em]$
We then obtain from Eq.~12 the normalized form of the PDF :

\begin{equation}
\boxed{
\begin{aligned}
\mathcal{P}_{\delta_\ell \nu}(x)
\approx
\frac{e^{\alpha(c_2 - c_1)}}{
\sqrt{2\pi}
\sqrt{
2 \alpha c_2 x^2 e^{2\alpha (h^\star + c_2 - c_1)} + 1
}
}
\times
\exp\!\left[
-\alpha\!\left(
\frac{(h^\star-c_1)^2}{2c_2}-h^\star
\right)
- \frac{1}{2}
x^{2}
e^{2\alpha (h^\star + c_2 - c_1)}
\right]
\end{aligned}
}
\tag{31}
\end{equation}

which is valid if $h^\star$ is such that $\frac{\partial f}{\partial h}(h^\star,\alpha,\sigma e^{\alpha (c_2-c_1)} x)=0$.

$\\[0.1em]$
As in the non-normalized case, we provide the plots of the obtained PDF in linear ang log cases using Julia programming language.

then we get from Eq.~30 :

\end{equation}

\subsection{Case B: solving \(\frac{\partial f}{\partial h}(h,\alpha,\sigma e^{\alpha (c_2-c_1)} x)=0\) via the Lambert \(W\) function}

We want to find \(h^\star\) such that $\frac{\partial f}{\partial h}(h^\star,\alpha,\sigma e^{\alpha (c_2-c_1)}x) = 0$.
Thanks to Eq.~19, we have :

\begin{equation}
\boxed{
h^\star(\alpha,\sigma e^{\alpha (c_2-c_1)}x)
= (c_1 + c_2)
- \frac{1}{2\alpha}
W\!\left(
2\alpha c_2 x^2 e^{4\alpha c_2}
\right)
}
\tag{33}
\end{equation}

We can now plug the obtained $h^\star$ into Eq.~30. Let $W=W\!\left( 2\alpha c_2 x^2 e^{4\alpha c_2} \right)$. We get :

\begin{equation}
\boxed{
\mathcal{P}_{\delta_\ell \nu}(x)
\approx
\frac{1}{
\sqrt{2\pi}\sqrt{2 \alpha c_2 x^2 e^{4 \alpha c_2-W} + 1}}
\times
\exp\left[
-\frac{\alpha}{2} \left( \frac{1}{c_2} \left( \frac{W}{2\alpha} \right)^2 - 3c_2 \right)
-\frac{1}{2} x^2 e^{4 \alpha c_2 - W}
\right]
}
\tag{34}
\end{equation}

i.e.

\begin{equation}
\boxed{
\mathcal{P}_{\delta_\ell \nu}(x)
\approx
\frac{e^\frac{3}{2}c_2 \alpha}{\sqrt{2\pi}}
\frac{e^{-\frac{2W + W^2}{8c_2 \alpha}}}{\sqrt{1+W}}
}
\tag{35}
\end{equation}

which is the same equation as (Granero Belinchón et al., 2017, Eq.~18).

\section{Appendix - Laplace's approximation theorem}
Let $I=[a,b]$ be an interval, $\varphi\in C^2(I,\mathbb{R})$
and $g\in C^0(I,\mathbb{C})$. Assume that:
\begin{enumerate}
    \item[(i)] For all $t>0$, $\displaystyle \int_a^b e^{t\varphi(x)} |g(x)|\,dx < +\infty$;
    \item[(ii)] $\varphi'$ vanishes at a unique point $x_0\in I$ and $\varphi''(x_0)<0$;
    \item[(iii)] $g(x_0)\neq 0$.
\end{enumerate}
Then
\[
\int_a^b e^{\,t\varphi(x)}\, g(x)\,dx
\sim
\sqrt{\frac{2\pi}{t\,|\varphi''(x_0)|}}\,
e^{\,t\varphi(x_0)}\, g(x_0)
\qquad\text{as } t\to +\infty .\]
